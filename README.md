# Cooking Masterclass - Course Catalogue

A responsive Vue.js single-page application showcasing cooking courses from world-class chefs. Users can browse courses, filter by skill level, and save their favourites to a wishlist.

## Project Overview

This is an interactive catalogue prototype for Cooking Masterclass, an online platform for cooking workshops. The app displays course cards with details including title, chef name, price, skill level, and availability. Users can filter courses and save them to a personal wishlist, with a live counter displayed in the page header.

## Features

- **Dynamic Course Catalogue** — 8 cooking courses rendered from local data (no hard-coded duplicates)
- **Wishlist Functionality** — Save/unsave courses with animated counter in the header
- **Sold Out Indicators** — Unavailable courses are clearly marked and disabled for saving
- **Skill Level Filtering** — Filter courses by Beginner, Intermediate, or Advanced
- **Responsive Design** — Optimised for both desktop and mobile devices
- **Smooth Animations** — Hover effects, card lift, image zoom, and wishlist pop animations
- **Currency Formatting** — Prices displayed in USD with proper formatting

## Tech Stack

- Vue 3 (Composition API with `&lt;script setup&gt;`)
- Vite (build tool)
- CSS3 (scoped styles + animations)
- No external API — all data is local
